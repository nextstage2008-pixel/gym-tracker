# gym-tracker v2.0 — エニタイムフィットネス美園店版 設計

日付: 2026-09-14　対象: `gym-tracker/`（index.html 自己完結PWA）

## 背景
GOLD'S GYM からエニタイムフィットネス美園店（https://www.anytimefitness.co.jp/misono/）へ移籍。
店舗のマシンラインアップに合わせてトレーニングメニューを再構築し、画面・アイコンをエニタイムのブランドに合わせる。
記録は新スタート（旧記録は表示しない）。

## 確定した判断（ユーザー回答）
1. メニュー構造は **A/B交互のまま**（週3回 月水金、A→B→A…）。
2. **マシンのみ**（フリーウェイトは使わない）。
3. 旧記録は **クリア**（保存キーを変えて新規スタート。旧データは端末内に残るだけ）。
4. ロゴは **公式「走る人」SVG** を使用（個人利用）。
5. 目標設定（開始日・目標日・開始体重・目標体重）は **ユーザーが自分で入力**できるようにする。

## 1. ブランド・見た目
- ダークUIは維持。アクセント色を黄 `#FFEC00` → 紫 `#6244bb`（公式SVG `icon_anytime_reg.svg` の fill）に全置換。`--gold-dim` 相当は `#3f2c80` 程度の暗い紫。
- Bメニュー系の赤 `#ff4438` → シアン `#00acce`（公式サイト common2021.css の差し色）。
- ヘッダー: 公式「走る人」ロゴを **インラインSVG**（紫の丸に白抜き）で埋め込み。ブランド名「ANYTIME FITNESS」、サブ「MISONO」。旧base64 PNGロゴは削除。
- アイコン icon-192.png / icon-512.png: 公式アプリアイコンのグラデ `#6e38d5 → #581acf` の角丸四角に白の走る人。headless Edge（msedge --headless=new --screenshot）で公式SVGからPNG生成し、Pillowで192へ縮小。
- manifest.json: name「Anytime Fitness ジム記録」、description をエニタイム表記に、theme_color/background_color は現行の黒系を維持。
- `<title>` と `apple-mobile-web-app-title` は「ジム記録」のまま。

## 2. メニュー（各7種目＋有酸素）
回数10回固定・「全セット10回できた✔」で次回 +inc（脚系5kg／その他2.5kg）、未達は据え置き、のルールは不変。

| 順 | 種目 | 部位 | set | rest | inc |
|---|---|---|---|---|---|
| 1 | レッグプレス | 脚・お尻 | 3 | 90秒 | 5 |
| 2 | チェストプレス | 胸・肩・腕 | 3 | 75〜90秒 | 2.5 |
| 3 | ラットプルダウン（マルチジャングル） | 背中 | 3 | 75〜90秒 | 2.5 |
| 4 | シーテッドレッグカール | もも裏 | 2 | 60秒 | 2.5 |
| 5 | ショルダープレス | 肩 | 2 | 60〜75秒 | 2.5 |
| 6 | ヒップアブダクション/アダクション | お尻・内もも | 2 | 60秒 | 2.5 |

| 順 | 種目 | 部位 | set | rest | inc |
|---|---|---|---|---|---|

- 各種目の `machine`（どんな機械？）・`note`（フォームのコツ）は Life Fitness / Hammer Strength のマシン前提で全て書き直す。似た形の見分け方（レッグエクステンション vs シーテッドレッグカール、フライ vs リアデルトは同じマシンの向き違い、ラットプルダウンはマルチジャングルの一部 等）を含める。

## 3. データ・新スタート
- `KEY` を `gymtracker_v1` → `anytime_v1`。`APP_VER` を v2.0。sw.js の `CACHE` を `gymtracker-v4`。
- SEED.settings = `{ startDate: <初回起動日>, startWeight: null, goalWeight: null, goalDate: null }`。
  `startDate` は load() 時に未設定なら今日を入れる。
- **初回目標カード**: `startWeight` または `goalWeight` または `goalDate` が未設定の間、今日タブの先頭に「🎯 はじめに目標を設定」カードを表示（開始日〔既定=今日・変更可〕・開始体重・目標体重・目標日、保存ボタン）。保存後は消え、以降は設定タブの既存欄で編集。
- 体重タブ・進捗タブの目標線／予測は目標未設定時は非表示にし、例外で落ちない。
- JSONインポートは新旧どちらの形式も受け付ける（`menus`/`settings` の存在チェックは現行どおり）。

## 4. 検証
- `node --check` 相当の構文チェック（scriptを抜き出して `node -e`）。
- headless Edge で 今日（初回カードあり／なし）・カレンダー・体重・設定 の4画面をスクリーンショットし目視（色・ロゴ・レイアウト崩れ）。
- 手動シナリオ: 新規状態 → 目標保存 → A記録（重量入力・✔）→ 次回B提案表示 → JSONエクスポート/インポート。
- commit/push → GitHub Pages 反映 → iPhoneでホーム画面アイコンを削除して再追加（アイコン差し替えのため）。
